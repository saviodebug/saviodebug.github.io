# Savio Junior

Código do meu portfólio pessoal.

Sou Savio Busana Beckhauser Junior, estudante de Ciência da Computação na Univali e estagiário de TI na Elastri Engenharia. Desenvolvo aplicações para Windows, bots para Discord e projetos web.

[Acesse o portfólio](https://saviodebug.github.io/)

## Os projetos

Projetos apresentados no site:

- **[YOSHI Control Studio](https://github.com/saviodebug/Macro-Yoshi):** aplicação Windows para macros, atalhos e perfis personalizados, com editor Lua e distribuição de atualizações.
- **[YoshiBot](https://github.com/saviodebug/YoshiBot):** bot para Discord desenvolvido em Python, com atendimento por tickets, moderação e integração com YouTube.
- **[ConfereAí (extensão)](https://github.com/saviodebug/ConfereAi):** extensão de navegador com uma API para apoiar a análise de sinais de risco em notícias e imagens.

- **[ConfereAí (site)](https://confereai-site.vercel.app/):** site educativo com artigos, critérios e fontes para apoiar a leitura crítica de notícias, desenvolvido com Carolina Jardim Ribeiro em HTML, CSS e JavaScript.
